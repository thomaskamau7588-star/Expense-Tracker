# Expense Tracker

## Project Description
The Expense Tracker is a web application that helps users manage their daily expenses. Users can add, view, delete, and filter expenses by category while automatically calculating their total daily spending.

## Features
- Add expenses with a description, amount, and category.
- View all recorded expenses.
- Delete expenses.
- Filter expenses by category.
- Calculate total daily expenses.
- Save expenses using LocalStorage.
- Responsive user interface.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git and GitHub

## JavaScript Concepts Applied
- Object-Oriented Programming (OOP)
- Classes and objects
- Destructuring
- Array methods (map, filter, reduce)
- Spread and rest operators
- LocalStorage

## How to Run the Project

1. Clone the repository:
   
   git clone https://github.com/thomaskamau7588-star/Expense-Tracker

2. Open the project folder in VS Code.

3. Open `index.html` using Live Server.

4. Start adding and managing your expenses.
